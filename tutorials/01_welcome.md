# Welcome to Heaven3D

Heaven3D is a free 3D game engine written in Python. It draws the 3D world, runs physics, plays sounds and reads your keyboard and mouse. You build the world in the **editor** and the engine brings it to life when you press **Play**.

## How the Hub works

The Hub is your home screen, like Unity Hub. From here you:

- create **projects** from templates and open them in the editor
- **play** a project without the editor around it
- follow these **offline tutorials** — no internet needed

## What is inside a project

Every project is just a folder. You can copy, zip or back it up like any other folder.

```
My Game/
├── main.heaven3d      <- your scene (the level)
├── project.json       <- name and template (used by the Hub)
├── assets/            <- models, textures, sounds you use
└── scripts/           <- your own Python game logic (blueprints)
```

> TIP: Put every model, texture and sound you use **inside** the project's assets folder before importing it. Paths are then saved relative to the project, so the game still works when you move or share the folder.

## Your learning path

1. Editor basics — move around and change objects
2. Build your first level
3. Make it a game without code
4. Import models from Blender and the web
5. Physics
6. Terrain, buildings and effects
7. Write your own game rules in Python
8. Share your game

Click **Mark as done** at the top when you finish a tutorial — the Hub remembers your progress.
